Why Pith

Accessible to the last detail

Scales with text size

Zero hard-coded pixels — every size is rem-based. Bump your browser or OS font size and the whole UI scales proportionally, nothing breaks.

Keyboard & screen-reader ready

ARIA semantics, managed focus, and full keyboard navigation are built into every component — not bolted on.

Respects reduced motion

Every animation ships a prefers-reduced-motion fallback and quiets itself when the OS asks.

High-contrast safe

Built-in forced-colors support keeps every component legible in Windows High Contrast mode.

Themeable with one attribute

Ink, Glass, and Brutal via a single data-theme. Pure CSS custom properties — zero runtime, no flash.

~20kb, runs anywhere

One tree-shakeable, MIT-licensed package for React, Vue, Svelte, Angular, or plain HTML.
