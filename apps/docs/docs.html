pith-accordion

Accordion

Accessible, animated disclosure panels. Three variants: Default (contained card), Flush (ruled lines, full-bleed), and Separated (each item is its own card). The panel uses a CSS grid-template-rows animation — no JS height measurement needed. Add multiple to allow more than one item open at once.

Default

What is Pith? Pith (@pith/ui) is a themeable, accessibility-first Web Component library built on Lit 3. Drop in one attribute — data-theme="ink", "glass", or "brutal" — and every component adapts instantly. Is it framework-agnostic? Yes. Pith ships as standard Custom Elements. Works with React, Vue, Svelte, Angular, or plain HTML. The @pith/react package provides typed React wrappers with full event forwarding. How is dark mode handled? Add data-dark to <html>. Each theme has independent light and dark token sets — toggling dark mode never overrides your chosen theme.

Flush

How do I install it? npm install @pith/ui lit — that's it. Lit is the only peer dependency. Alternatively, load from a CDN for zero-build usage. What about tree-shaking? Each component is a standalone ES module. Import only what you need: import '@pith/ui/button'. Unused components add zero bytes to your bundle. Is it accessible? Each item uses a <button> trigger with aria-expanded and aria-controls. The panel has role="region" and aria-labelledby. Focus is never trapped — keyboard navigation flows naturally.

Separated · with icons

Theming system Tokens live in themes.css as CSS custom properties under the --ui-* namespace. Switching themes is one attribute change. Every component — including this one — reads from those tokens through Shadow DOM inheritance. Animation philosophy Pith believes animations should be purposeful and respectful. Durations are short (150–320 ms), easing is physics-informed, and every motion honours prefers-reduced-motion. The accordion panel uses a CSS grid trick — no JS height polling, no layout thrash. Browser support Targets all modern evergreen browsers. The grid animation requires Chrome 107+, Firefox 110+, and Safari 16+. For older targets, the panel opens/closes without a height transition — content is always accessible.

Multi-open [multiple]

Multiple items can be open simultaneously Add the multiple attribute to <pith-accordion> to switch from exclusive ("accordion") behavior to independent ("disclosure") behavior. Both of these are open at the same time Without multiple, opening this item would close the one above. With it, both stay open until individually collapsed. This item is disabled The disabled attribute blocks interaction and renders the trigger at reduced opacity. The panel content is still in the DOM (for SEO / copy-paste), just inaccessible.

pith-breadcrumb

Breadcrumb

Accessible navigation landmark. Renders a <nav aria-label> containing an ordered list of crumbs. Each item is either a navigable <a> link or a static <span aria-current="page"> for the active step. Separators are rendered inside Shadow DOM — the first item's separator hides itself automatically via :host(:first-child), no parent coordination needed. Ink and Glass use a chevron; Brutal uses a bold monospace / and frames the entire nav in a hard-bordered strip.
